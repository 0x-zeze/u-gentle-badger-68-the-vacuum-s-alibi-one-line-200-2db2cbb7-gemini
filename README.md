# The Vacuum's Alibi: One Line, 200 Characters

One original one-line excuse a robot vacuum gives for missing a spot, written by a program, for the make.fun bounty
[u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7).

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` — deterministically, with no
network access.
